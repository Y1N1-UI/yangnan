底部标签栏（SVG 图标）

同一张标签栏换用 SVG 实现：iconfont.js 把整幅精灵图注入页面，每个图标用 use 引用对应的 symbol 绘制。脚本会摘掉图形上写死的填充色，让图标颜色随文字属性走。

图标来源
font 目录 iconfont 项目 5238917
渲染方式
svg use 引用 symbol，脚本注入精灵图
徽章配置
数字徽章两枚，红点一枚
浏览 icon-browser，右上角红点提示
分类 icon-classification，无提示
视频 icon-video，数字徽章 6
喜欢 icon-love，数字徽章 99+

SVG 图标按矢量绘制，放大不糊；选中态的颜色变化由 CSS 的 color 加 fill currentColor 完成，这也是 SVG 方式比字体方式更灵活的地方。
